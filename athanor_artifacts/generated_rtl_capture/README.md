# BOOM Generated RTL Capture

Status: pending.

BOOM is a generator-first Chisel/Chipyard design. A module-local optimization
packet requires a pinned generated RTL snapshot before synthesis, proof, or
simulation receipts can be meaningfully compared.

Close this package when it contains:

1. Exact BOOM commit and `CHIPYARD.hash`.
2. Generator command and config name.
3. Generated Verilog files or a reproducible generation script.
4. SHA-256 manifest for generated RTL.
5. First target-selection note for the module-local packet.

Until this package is complete, this fork makes no BOOM optimization or proof
claim.
